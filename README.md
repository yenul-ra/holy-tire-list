# Tier-List

A simple tier list maker that runs in your browser. Upload images, drag them into tiers, rename the tiers, and save or export your list. No server or login needed.

## What it does

- Rename, recolor, add, delete and reorder tiers
- Upload images and drag them between tiers
- Add a title to an image, resize it, replace it or delete it
- Save and load your list in the browser
- Export as PNG or JSON, and import JSON back

## How to use

1. Click **Add Image** and pick your pictures.
2. Drag them from Unranked into a tier.
3. Click a tier name to rename it.
4. Click an image to edit it (right-click on Desktop).
5. Use **Save**, **Export PNG** or **Export JSON** when you're done.

## Good to know

Everything is stored in your own browser, so lists don't sync between devices.
Use Export JSON if you want a backup or want to move a list.
100% sure we don't keep records about your rankings.
